# Review AI Assistant

## Карточка промпта

**Название:** Review AI Assistant  
**Версия:** v2.0.0  
**Владелец:** Andrei Golubev  
**Статус:** Stable  
**Модель:** OpenAI GPT-4.1-mini  
**Теги:** `reviews`, `customer-support`, `classification`, `analytics`, `LLM`

## Цель

Шаблон предназначен для анализа клиентских отзывов сотрудниками компании.

Промпт позволяет:

- классифицировать отзывы по тональности и типу обращения;
- определять основные и второстепенные темы;
- оценивать критичность обращения;
- определять необходимость эскалации;
- формировать рекомендации сотруднику;
- готовить проект ответа клиенту;
- анализировать группу отзывов и выявлять повторяющиеся проблемы.

## Переменные

| Переменная | Назначение |
|---|---|
| `{company_name}` | Название компании |
| `{company_description}` | Описание компании |
| `{response_language}` | Язык результата |
| `{review_data}` | Один отзыв или набор отзывов |
| `{company_rules}` | Правила компании |
| `{knowledge_context}` | Релевантный контекст из базы знаний |

## Вход

Один клиентский отзыв или набор отзывов, правила компании и при наличии релевантный контекст из базы знаний.

## Выход

Для одного отзыва:

- тональность;
- тип обращения;
- темы;
- критичность;
- необходимость эскалации;
- основная суть обращения;
- рекомендуемое действие;
- проект ответа клиенту.

Для группы отзывов:

- размер выборки;
- распределение по тональности;
- основные темы;
- повторяющиеся проблемы;
- положительные тенденции;
- критические обращения;
- краткие рекомендации.
