# Prompt Library

Библиотека шаблонов промптов для работы с LLM с поддержкой версий и тестирования.

Промпты оформляются как самостоятельные командные шаблоны с описанием назначения, переменных, входных и выходных данных, версий и тест-кейсов.

## Промпты

### Review AI Assistant

Шаблон для анализа клиентских отзывов, классификации обращений, определения критичности и необходимости эскалации, подготовки проектов ответов и аналитических сводок.

**Версия:** v2.0.0  
**Статус:** Stable  
**Модель:** OpenAI GPT-4.1-mini  
**Владелец:** Andrei Golubev
